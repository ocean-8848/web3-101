# Web3 101

面向零基础工程师的 Web3 学习手册。它是一个单页 HTML 应用，包含 15 个模块、194 篇文章（含 178 篇子文章）和 48 个交互实验，每个模块均附阶段测验，并配套 `examples/` 最小可运行代码脚手架。在浏览器里打开就能读，不需要服务器。

## 阅读手册

```bash
./build.sh          # 把 src/ 拼成单文件 index.html
open index.html
```

`index.html` 是构建产物，不入库。改完 `src/` 后重新运行 `build.sh` 即可。

改完源码后，可以跑一遍冒烟测试。它会加载全部文章，检查交叉引用和插图：

```bash
node tools/smoke.js
```
