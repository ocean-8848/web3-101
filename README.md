# Web3 101

面向零基础工程师的 Web3 学习手册。它是一个单页 HTML 应用，分三部分（公共基础、应用领域、毕业项目），包含 16 个模块、196 篇文章（16 篇模块总览、164 篇子文章和 16 套阶段测验）和 48 个交互实验，每个模块均附阶段测验，并配套 `examples/` 最小可运行代码脚手架。在浏览器里打开就能读，不需要服务器。

## 阅读手册

```bash
./build.sh          # 把 src/ 拼成单文件 index.html
open index.html
```

`index.html` 是构建产物，不入库。改完 `src/` 后重新运行 `build.sh` 即可。

改完源码后，可以跑一遍冒烟测试。它会加载全部文章，检查交叉引用和插图：

```bash
node tools/smoke.js
```
