# Web3 从 0 到 1

面向零基础工程师的 Web3 学习手册。它是一个单页 HTML 应用，包含 13 个模块、约 150 篇子文章和 40 多个交互实验，大多数模块附阶段测验。在浏览器里打开就能读，不需要服务器。

## 课程模块

| 模块 | 主题 |
|---|---|
| M00 | Web3 是什么：所有权从账号转到私钥 |
| M01 | 区块链基础 & Go 后端 |
| M02 | 智能合约开发：EVM、Solidity 与合约安全 |
| M03 | Web3 大前端 |
| M04 | 公链、基础设施与密码学 |
| M05 | 合规与监管：工程师需要懂的规则 |
| M06 | DeFi 协议：稳定币、AMM、借贷与代币经济 |
| M07 | 钱包：从助记词到企业级托管 |
| M08 | 交易所：CEX 与 DEX |
| M09 | 预测市场与衍生品 |
| M10 | Agent & Web3 |
| M11 | 更多应用赛道：身份、社交、存储、RWA 与游戏 |
| M12 | 综合毕业项目：从零交付一个链上产品 |

## 阅读手册

```bash
./build.sh          # 把 src/ 拼成单文件 index.html
open index.html
```

`index.html` 是构建产物，不入库。改完 `src/` 后重新运行 `build.sh` 即可。

改完源码后，可以跑一遍冒烟测试。它会加载全部文章，检查交叉引用和插图：

```bash
node tools/smoke.js
```

## 目录结构

```
web3-101/
├── README.md
├── LICENSE          MIT 许可证
├── SPEC.md          子文章写作规范：结构、助手函数、编号规则
├── FIGURES.md       主视觉图（art kit）写作指南
├── build.sh         把 src/ 拼成 index.html
├── src/
│   ├── head.html    页面骨架与样式
│   ├── core.js      内容助手函数与实验助手函数
│   ├── ch-*.js      首页与各模块总览
│   ├── sub-mXX.js   各模块子文章
│   ├── labs-*.js    交互实验
│   ├── stage-*.js   各模块阶段测验
│   └── tail.js      实验室页、术语表页与启动代码
└── tools/           冒烟测试、插图检查、插图预览
```
